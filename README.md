# 萌娘百科（miyu-scripts-moegirl-query）

给 Miyu 的脚本工具 `moegirl`：查萌娘百科（zh.moegirl.org.cn）的动画、漫画、游戏、虚拟主播等 ACG 条目。

- 给名字就找最匹配的条目并打开，其余候选列在末尾；只想看有哪些条目用 `action=search`。
- 资料卡排成「键：值」，日文原名、声优这些都在；导航框、注释、图集、编辑邀请这类杂项去掉。
- 长条目先给导言和放得下的小节，放不下的列出编号、标题和字数，再用 `section` 取。

## 参数

| 参数 | 说明 |
|---|---|
| `query` | 条目名，尽量用中文；按标题**开头**匹配 |
| `title` | 准确的条目标题，写了就直接打开 |
| `action` | `auto`（默认）、`search`（只列标题）、`page`（按标题打开） |
| `section` | 只取一个小节：编号（如 `2.1`）或标题（如 `人物经历`），连同子小节 |
| `limit` | 列几个标题，1–20，默认 8 |
| `max_chars` | 正文最多几个字，1000–40000，默认 8000 |
| `format` | `md`（默认）或 `json` |

## 依赖与注意

- 只用 Python 标准库，不用登录。
- 萌娘百科对匿名访问只开放两样：标题搜索（只认开头）和页面正文。全文搜索、`api.php` 的解析接口都要登录，所以搜「葬送的芙莉莲 角色」这种句子是搜不到的，要给条目名。
- 镜像站 moegirl.uk 已经打不开（2026-10 实测 530），只用主站。
