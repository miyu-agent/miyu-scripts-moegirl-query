# Moegirlpedia (moegirl-query)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `moegirl`, which looks up anime, manga, games, VTubers and other ACG entries on Moegirlpedia (zh.moegirl.org.cn).

- When you give a name, the tool finds the best-matching entry and opens it, and lists the other candidates at the end; if you only want to see which entries exist, use `action=search`.
- The infobox is laid out as "key: value" lines, and details such as the original Japanese name and the voice actors are kept; clutter such as navigation boxes, footnotes, galleries and invitations to edit is removed.
- For a long entry, the tool first gives the introduction and the sections that fit; the sections that do not fit are listed with their number, heading and length, and you can then fetch them with `section`.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `query` | The name of the entry to look up, in Chinese where possible; it matches the **beginning** of titles |
| `title` | The exact entry title; when it is given, that entry is opened directly |
| `action` | `auto` (default), `search` (list titles only), `page` (open by title) |
| `section` | Fetch only one section: by number (for example `2.1`) or by heading (for example `人物经历`); its subsections are included |
| `limit` | The number of titles to list, 1–20, default 8 |
| `max_chars` | The maximum number of characters of page text to return, 1000–40000, default 8000 |
| `format` | `md` (default) or `json` |

## Dependencies and notes

This section explains what the tool depends on and the limits Moegirlpedia places on anonymous access.

- The tool uses only the Python standard library and needs no login.
- Moegirlpedia opens only two things to anonymous access: title search (matching only the beginning) and page text. Full-text search and the parse API of `api.php` both require a login, so a sentence such as `葬送的芙莉莲 角色` finds nothing; you need to give the entry name.
- The mirror site moegirl.uk can no longer be opened (it returns 530), so the tool uses only the main site.
