# 萌娘百科（moegirl-query）

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `moegirl`，用来查询萌娘百科（zh.moegirl.org.cn）上动画、漫画、游戏、虚拟主播等 ACG 条目。

- 给出名字时，工具会找到最匹配的条目并打开，其余候选列在末尾；如果只想看有哪些条目，使用 `action=search`。
- 资料卡会排成「键：值」的形式，日文原名、声优这些信息都会保留；导航框、注释、图集、编辑邀请这类杂项会去掉。
- 对于长条目，工具先给出导言和放得下的小节，放不下的小节会列出编号、标题和字数，之后可以用 `section` 获取。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `query` | 要查询的条目名，尽量使用中文；按标题的**开头**匹配 |
| `title` | 准确的条目标题，填写以后直接打开这个条目 |
| `action` | `auto`（默认）、`search`（只列出标题）、`page`（按标题打开） |
| `section` | 只获取一个小节：可以写编号（例如 `2.1`）或者标题（例如 `人物经历`），结果包含它的子小节 |
| `limit` | 列出的标题个数，1–20，默认 8 |
| `max_chars` | 正文最多返回的字数，1000–40000，默认 8000 |
| `format` | `md`（默认）或者 `json` |

## 依赖与注意

这一节说明工具依赖什么，以及萌娘百科对匿名访问的限制。

- 工具只使用 Python 标准库，不需要登录。
- 萌娘百科对匿名访问只开放两项功能：标题搜索（只按开头匹配）和页面正文。全文搜索和 `api.php` 的解析接口都需要登录，所以搜索 `葬送的芙莉莲 角色` 这样的句子搜不到任何结果，需要给出条目名。
- 镜像站 moegirl.uk 已经无法打开（返回 530），所以工具只使用主站。
